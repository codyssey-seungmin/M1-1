# 대시보드 제출: 스크린샷과 필터 변경 시나리오

제출 방식: 보너스 서비스화 (3) 스크린샷 세트 + 필터/기간 변경 시나리오 설명.
실행 방법은 [README](README.md)를 참고한다.

## 캡처 방법

각 조건을 선택하고 선택 상자를 닫는다. 제목, 네 가지 조건, 요약 카드와
그래프가 함께 보이도록 캡처한다. 한 화면에 들어오지 않으면 화면을 두 장으로 나눠도 된다.
Windows의 Win+Shift+S로 캡처하고 아래 파일명으로 `screenshots/`에 PNG 저장한다.
조건과 수치가 잘리지 않게 하며 서로 다른 조건의 화면을 합성하지 않는다.

## 변경 시나리오와 의미

1. **기본 비교:** 2016~2025년·30℃를 선택한다. 정적 리포트의 최근 10년 결과와 같음을 확인한다.
2. **기준 변경:** 연도와 기간을 유지하고 33℃로 변경한다. 더 높은 기온 기준에서
   고온일수와 연속일수가 감소하며, 요약 카드·그래프·표가 함께 바뀌는지 확인한다.
3. **미완결 연도:** 기준을 30℃로 돌리고 시작 연도를 2026년으로 변경한다.
   종료 연도가 2026년으로 조정되고 모든 비교가 1~8월로 제한되는지 확인한다.
   기간 선택 상자는 잠기며 안내 문구가 나타난다. 56일은 연간 총량이 아니다.

## 검증 기록

- 사용자 확인: 2006~2025년에서 2016~2025년으로 변경했을 때 안내한 수치와 일치함을 대화에서 확인했다.
- 계산 검증: `verify_dashboard.py`가 3개 기준 × 20개 연도, 1~8월 21개 연도,
  단일 2024년 필터 결과를 기존 Python 분석과 대조한다.
- 계산 검증은 실제 브라우저의 이벤트·레이아웃 검증을 대신하지 않는다.
- 에이전트 브라우저는 로컬 HTML 접근이 정책상 차단되어 자동 UI 캡처를 수행하지 못했다.
- 현재 위 3개 스크린샷은 사용자 저장 대기 상태다. 저장 후 이미지의 조건·수치를 확인하고 리포트에 연결한다.
