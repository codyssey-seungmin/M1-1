# 창원 더위 탐색 대시보드

## 로컬 실행

프로젝트 폴더에서 다음을 실행한다.

```powershell
.\.venv\Scripts\python.exe export_dashboard.py
Start-Process .\dashboard\dist\index.html
```

`dist/index.html`을 파일 탐색기에서 더블클릭해도 된다.
데이터를 `data.js`로 함께 제공하므로 별도 서버·로그인·인터넷 없이 작동한다.
CSV를 업데이트하면 `prepare_data.py`와 `export_dashboard.py`를 순서대로 다시 실행한다.
HTML, CSS, app.js, data.js는 같은 폴더에 유지한다.

## 현재 기능

- 시작·종료 연도, 고온 기준(28/30/33℃), 비교 기간(연간/1~8월) 변경
- 연평균 고온일수, 연도별 최장 연속일수 평균, 최고기온 결측 일수
- 연도별 고온일수 그래프와 계산표
- 2026년을 포함하면 모든 연도를 1~8월로 제한
- 결측일에 대한 고온 여부 두 가정의 범위 표시. 원본은 보간하지 않음
- 고온일 비율은 선택 기간의 전체 날짜를 분모로 사용
- 시작 연도가 종료 연도보다 크면 종료 연도를 시작 연도로 조정하고 안내

## 첫 화면 확인 시나리오

1. 2006~2025년, 1~12월, 30℃: 연평균 고온일수 45.45~45.50일, 최장 연속일수 평균 18.1일.
2. 시작 연도를 2016년으로 변경: 고온일수 53.7~53.8일, 최장 연속일수 평균 22.2일.
3. 고온 기준을 33℃로 변경: 고온일수 22.7~22.8일, 최장 연속일수 평균 11.2일.
4. 시작·종료를 2026년, 기준을 30℃로 변경: 1~8월 자동 선택, 56일·32일·결측 0일.

스크린샷 세트와 필터 검증 기록은 다음 단계에서 추가한다.
현재 계산 함수의 값과 문법은 점검했으며, 실제 브라우저 화면·키보드 동작은 후속 확인 대상이다.
지원하는 브라우저에서는 `set_heat_filters` WebMCP 도구를 등록하며,
미지원 브라우저에서는 일반 선택 상자가 그대로 동작한다. 지원 환경에서의 도구 호출 검증은 아직 수행하지 않았다.
