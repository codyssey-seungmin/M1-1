- 지점: 창원(155)
- 선택 요소: 평균기온, 최저기온, 최고기온 (℃)
- 수집일: 2026-09-10
- 수집 방법: 사이트에서 로그인 후 아래 기간별로 조회하고 CSV 다운로드
- 원본 인코딩: CP949
- 원본은 파일명만 변경하고 내용은 수정하지 않았다.

## 이용 시 주의

기상청 제공 자료임을 표시한다. 데이터의 이용·재배포에는 제공기관의
이용조건을 적용하며, 프로젝트 코드의 라이선스가 데이터에 자동 적용되지는 않는다.
구체적인 이용허락 유형은 원 출처의 안내를 확인한다.

## 1차 품질 확인

실행: `.\.venv\Scripts\python.exe check_data.py`

- 전체 7,548행, 모두 창원(155).
- 날짜 누락, 날짜 중복, 조회 기간 밖 날짜 없음. 각 파일은 날짜 오름차순.
- 평균기온 결측 없음.
- 2025-01-10 최고기온 결측, 2025-01-11 최저기온 결측.
- 확인 가능한 값에서 최저 ≤ 평균 ≤ 최고 순서 위반 없음.
- 이 검사는 모든 관측오류가 없음을 보증하지 않는다.
- 결측값은 아직 채우거나 삭제하지 않았다. 분석 지표별 처리 기준은 이후 결정한다.

2006~2025년을 본 분석에 사용하고, 2026년은 과거의 동일한 1~8월과만 비교한다.

## 통합 데이터

`prepare_data.py`로 `processed/changwon_daily.csv`를 재생성한다.
원본 값은 유지하고 열 이름을 영어로 통일하며 UTF-8 BOM 인코딩으로 저장한다.

| 열 | 의미 |
|---|---|
| station, station_name | 관측소 번호와 이름 |
| date | 관측 날짜 |
| tavg, tmin, tmax | 일평균·일최저·일최고기온(℃) |
| source_file | 해당 행의 원본 파일명 |
| year, month | 날짜에서 추출한 연도와 월 |
| period | 2006-2015 / 2016-2025 / 2026-partial |
| is_main_analysis | 2006~2025년이면 True, 2026년이면 False |

날짜 누락·중복, 잘못된 지점, 숫자로 해석할 수 없는 기온이 발견되면
통합을 중단한다. 기온 결측값은 빈칸으로 저장하며 0℃와 구분한다.
