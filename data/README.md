- 제공기관: 기상청
- 출처: https://data.kma.go.kr/data/grnd/selectAsosRltmList.do?pgmNo=36
- 자료: 종관기상관측(ASOS) 일자료
- 지점: 창원(155)
- 선택 요소: 평균기온, 최저기온, 최고기온 (℃)
- 수집일: 2026-09-10
- 수집 방법: 사이트에서 로그인 후 아래 기간별로 조회하고 CSV 다운로드
- 원본 인코딩: CP949
- 원본은 파일명만 변경하고 내용은 수정하지 않았다.

## 이용 시 주의

기상청 제공 자료임을 표시한다. 데이터의 이용·재배포에는 제공기관의
이용조건을 적용하며, 프로젝트 코드의 라이선스가 데이터에 자동 적용되지는 않는다.
구체적인 이용허락 유형은 원 출처의 안내를 확인한다.

## 1차 품질 확인

실행: `.\.venv\Scripts\python.exe check_data.py`

- 전체 7,548행, 모두 창원(155).
- 날짜 누락, 날짜 중복, 조회 기간 밖 날짜 없음. 각 파일은 날짜 오름차순.
- 평균기온 결측 없음.
- 2025-01-10 최고기온 결측, 2025-01-11 최저기온 결측.
- 확인 가능한 값에서 최저 ≤ 평균 ≤ 최고 순서 위반 없음.
- 이 검사는 모든 관측오류가 없음을 보증하지 않는다.
- 결측값은 아직 채우거나 삭제하지 않았다. 분석 지표별 처리 기준은 이후 결정한다.

2006~2025년을 본 분석에 사용하고, 2026년은 과거의 동일한 1~8월과만 비교한다.
